# peerbot

Default-deny host port helper for Inferno newcomers.
Broader assignments unlock only after `learn.sh`.

```bash
tools/peerbot/peerbot.sh list
tools/peerbot/learn.sh            # loco → grid → public → expert
tools/peerbot/peerbot.sh level
./try.sh                          # deny
./try.sh --allow loco             # after level 1
```

See [docs/PEERBOT.md](../../docs/PEERBOT.md).
